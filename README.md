# demos

Public, self-contained HTML builds of [Sankarasanjeevi](https://sankarasanjeevi.com/tools) Premiere Pro
panels, embedded as playable demos on the website. Each demo is the real panel UI bundled to
a single file with the Premiere bridge and licensing stubbed out, so the demo can never drift from
the shipping product.

Add `?skin=portfolio` to a demo URL to show it in the website's colours.

Built from the private source repo — do not edit these files by hand.
