# toolninja-demos

Public, self-contained HTML builds of [Tool Ninja](https://toolninja.framer.website/) Premiere Pro
panels, embedded as playable demos on the marketing site. Each demo is the real panel UI bundled to
a single file with the Premiere bridge and licensing stubbed out, so the demo can never drift from
the shipping product.

Built from the private source repo — do not edit these files by hand.
